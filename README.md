\# MonSiteWeb



Page web en HTML et CSS, versionnée avec Git et publiée sur GitHub.



\## TP 1 : premier dépôt local (TP-Git)



Commandes utilisées :



```

mkdir TP-Git

cd TP-Git

notepad notes.txt

git init

git status

git add notes.txt

git commit -m "Ajout de notes.txt avec trois lignes"

notepad notes.txt

git add notes.txt

git commit -m "Ajout d'une quatrieme ligne dans notes.txt"

git log --oneline

```



`git add` place les modifications dans la zone de préparation (index).

`git commit` enregistre ces modifications préparées dans l'historique du dépôt local, avec un message.
